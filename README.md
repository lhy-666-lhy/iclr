# SPACE

Code for SPACE, a robot-aware 3D policy.

Experiments folder:

- **RobotWin 2.0**: `policy/SPACE` (please prepare environment following the public RobotWin 2.0 repo)
- **RLBench2**: `RLBench2/SPACE` (please prepare environment following the public RLBench2 repo)

Train / eval scripts live in those two folders.
